# 📊 Matplotlib 101 Exercises & Dashboard Challenge

Complete solutions for Matplotlib visualization exercises including line charts, custom markers, vertical and stacked bar charts, and a 4-in-1 multi-panel dashboard.

## 📌 Exercises Included
1. **Monthly Sales Trend** (Custom line chart with dashed lines and square markers)
2. **Student Scores** (Custom line chart with starred markers and fill colors)
3. **Company Revenue** (Dotted line chart with diamond markers)
4. **Fruit Supply** (Vertical bar chart using object-oriented `fig, ax`)
5. **Students by Department and Gender** (Stacked bar chart with `ax.bar_label`)
6. **Bonus Dashboard Challenge** (2x2 grid layout visualizing 4 datasets simultaneously)

## 🚀 How to Run
```bash
pip install -r requirements.txt
python main.py
